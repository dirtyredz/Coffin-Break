Before capturing, read the "Capturing the badge" section in NEXUS.md — Steam's F12 and
PrintScreen both fail here, because pressing a key is what makes the badge disappear. Alt-tab
away and capture the game window from another app instead.

Let the badge run for several real minutes first. "Time paused — away 8m" sells the mod;
"away 3s" does not.
